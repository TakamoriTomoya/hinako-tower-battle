# Handoff: どうぶつタワーバトル アプリ画面（ポップ／ビタミンカラー）

## Overview
「どうぶつタワーバトル」アプリの3画面（ホーム、対戦、勝利結果）のモバイルUIデザイン。元気・ビタミンカラーのポップなトーンで作成。

## About the Design Files
このフォルダの HTML ファイルは **デザインリファレンス** であり、そのまま本番コードとして使う想定ではありません。見た目と挙動の意図を示すプロトタイプです。実際の実装は、対象コードベースの既存環境（React / Vue / SwiftUI / ネイティブなど）の作法に沿って再構築してください。環境が未定なら、プロジェクトに最も適したフレームワークを選定して実装してください。

## Fidelity
**Hifi（高精度）**: 色・タイポグラフィ・余白・角丸・シャドウは最終値として扱ってください。画像部分（動物イラスト・タワー写真）はプレースホルダーで、実素材に差し替えが必要です。

## Screens / Views

### 1. ホーム画面 (Home)
- **Purpose**: アプリ起動後の入口。対戦開始・練習への導線、直近の戦績表示。
- **Layout**: 縦フレックス、幅360px相当（スマホ1画面）。上から: ステータスバー(28px) → タイトル → ヒーロー画像(flex:1) → 統計チップ3つ横並び → ボタン2つ縦積み。全体パディング20px、gap 18px。背景は上部が薄黄色(#FFF6D9)から下部クリーム(#FFFBF0)への縦グラデーション。
- **Components**:
  - タイトル: "どうぶつタワーバトル"。Baloo 2, weight 800, 36px, line-height 1.05, 色 #4A4237（「タワーバトル」部分のみ #FF6F91）。中央揃え。
  - サブタイトル: "のんびりオンライン対戦ゲーム"。Nunito, weight 700, 13px, 色 #8A8168。
  - ヒーロー画像枠: 角丸24px、背景 #FFE7A3、flex:1で残り高さを占有。
  - 統計チップ（3つ、横に等間隔）: 角丸999px（ピル形）、padding 6px 14px、font-weight 800、13px。
    - 🏆 1240（レート）: 背景 #FFE1EA、文字 #D9436B
    - 🔥 3連勝: 背景 #E1F5E6、文字 #2FA363
    - 🪙 560（コイン）: 背景 #FFF1CC、文字 #C68A11
  - ボタン「対戦を始める」: primaryボタン、高さ52px、文字18px。
  - ボタン「練習する」: secondaryボタン、高さ48px、文字16px。

### 2. 対戦画面 (Battle)
- **Purpose**: リアルタイム対戦中の画面。タイマー、対戦相手情報、操作ボタン。
- **Layout**: 背景 #EFF8FF。上部に自分/相手のレートチップとタイマーを横並び。中央にタワー画像枠(flex:1, 角丸24px, 背景#DFF0FF)。下部に「あなたの番です！」テキストと操作ボタン3つ。
- **Components**:
  - 自分のレートチップ: "たろう 1240"、背景 #FFE1EA、文字 #D9436B、12px。
  - 相手のレートチップ: "みかん 1310"、背景 #E1F0FF、文字 #1E80C9、12px。
  - タイマー: "00:07"、Baloo 2, weight 800, 26px, 色 #3AAFFF、中央。
  - ターン表示テキスト: Baloo 2, weight 700, 18px, 色 #4A4237、中央。
  - 回転ボタン(左/右, ↺ ↻): ghostボタン、幅88px、高さ48px、文字20px。
  - 積むボタン: primaryボタン、幅130px、高さ48px、文字18px。

### 3. 勝利画面 (Result)
- **Purpose**: 対戦結果表示。レート変動、積んだ段数、再戦/ホーム導線。
- **Layout**: 背景は上部ピンク(#FFE1EA)からクリーム(#FFFBF0)への縦グラデーション。中央揃え縦フレックス。
- **Components**:
  - "VICTORY!" チップ: ピル型、背景 #FF6F91、文字 #FFFBF0。
  - "勝利！🎉" 見出し: Baloo 2, weight 800, 44px, 色 #4A4237。
  - 結果画像枠: 220×200px、角丸24px、背景 #FFE7A3。
  - レート行: "レート" / "1240 → 1268"（矢印後の数値のみ #FF6F91、他は #4A4237）。font-weight 800, 14px。
  - 積んだ数行: "積んだ数" / "14 段"。同スタイル。
  - ボタン「もう一度対戦する」: primaryボタン、高さ52px。
  - ボタン「ホームへ戻る」: secondaryボタン、高さ48px。

## Interactions & Behavior
- ボタンは押下時にわずかに縮小（scale 0.96、transition 0.1s）するタップフィードバックあり。
- 各ボタンにホバー色あり（下記トークン参照）。
- ボタンは下方向に4pxのソリッドシャドウ（立体的な「押せる」表現）。
- 画面遷移: ホーム→対戦（「対戦を始める」）、対戦→勝利画面（対戦終了時）、勝利画面→ホームまたは再戦。
